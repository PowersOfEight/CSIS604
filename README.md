# CSIS 604 - Distributed Computer Systems Architecture

---

## Syllabus at [Oaks](lms.cofc.edu)

---

### Programming Languages Used

Of course Leclerc is partial to `C`, but `python` is a useful alternative.

### Environment

- Most of this is going to be in a POSIX compliant or Unix environment
- Will be using containers (note, might need `docker` or maybe we'll use `podman`)

### Learning Outcomes

- Basic techniques for the design and construction of distributed systems.
- Learn and apply the theory of distributed systems, including architectures and models, processes and communications, computer networks, etc.
- Implement simple distributed systems that provide solutions for problems that are
  - Big data oriented
  - CPU intensive
  - Web-based
  - Cloud-based
- Research modern distributed systems problems
- Install and use software related to distributed systems
